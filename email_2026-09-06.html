  2. VLA/VLN 모델의 '크로스-임바디먼트'가 실증 단계에 들어섰다LimX Dynamics가 오픈소스 VLN 모델 LightNav-0을 사족 Oli와 휴머노이드 TRON 2에 제로샷으로 올려 사람 추종·자연어 물체 탐색을 수행했다. 하나의 내비게이션 브레인이 형상이 다른 두 플랫폼에서 재학습 없이 동작한다는 점이 핵심이다.
  3. 학습 데이터 병목을 우회하는 두 갈래 해법Astribot의 SmoothRL은 비동기 실행 온라인 RL로 실환경에서 직접 학습해 Dynamic Toss 39%→94%, Pen Capping 8%→83%를 달성했다. 반대편에서 X Square의 TwinDEX는 로봇 온보드 데이터 0으로 사람 시연만 전이해 24단계 화학 실험을 자율 완주했다(유효 처리량 최대 5.3배).
  4. 하드웨어 경쟁 축이 '핸드'와 '툴 인텔리전스'로 이동RLWRLD는 $19K WuJi Hand 2와 $50K SharpaWave를 정면 비교하며 가격이 사는 성능을 실측했고, ZINOVA는 TRON 2 위에 툴 인텔리전스를 얹어 거푸집 조립·철근 배근 같은 실제 건설 공정을 시연했다. 범용 팔·핸드 위에 도메인 스킬 레이어를 얹는 구조가 자리 잡는 중이다.

  6. 한국은 인재 양성과 현장 적용에서 존재감로보티즈 OH! GYM! 1기가 30일 만에 오픈소스 휴머노이드 AI Sapiens K1으로 장애물 보행·백플립까지 Sim2Real로 구현했고, 클로봇은 Spot+Orbit 예지보전 웨비나, 뉴로메카·트위니·코라스로보틱스는 전시·물류 성과를 공개했다.

SmoothRL: Efficient Online RL with Asynchronous Execution
